# Tester Beta kararı

Yerel Windows x64 teknik paketi doğrulandı. Genel Tester Beta onayı bekliyor. Yerel EXE ve teknik testler temiz Windows bilgisayarını veya gerçek oyun oturumunu ikame etmez. Özellikle 2D okunabilirliği, arama kolaylığı ve personel işlemlerinin akıcılığı insan tester tarafından denenmeli.
