# Kapalı Beta kararı

Yerel paket duman testi başarılı. v0.8.7 TESTER BETA altındaki Top Antrenoru klasörünü birlikte dağıtın. Top Antrenoru.exe ve iç bağımlılıklar birlikte kalmalı. Paket doğrulaması yalnızca Windows sistem yollarıyla, Python/Tcl harici konumları olmadan yapıldı. Oyunun üç tarihsel JSON dosyası kaynakla hash eşleşti. DAT arşivi yok. Kayıt konumu sürüme özel. BENI_OKU.txt paket içinde.

Genel Beta onayı verilmedi. Temiz Windows ve insan tester doğrulaması eksik. İlk kapalı turda taç ve disiplin frekansı, ekran ölçeklemesi ve eski kaydın seçilerek açılması izlenecek alanlardır. Premier League oynanabilir değil.
