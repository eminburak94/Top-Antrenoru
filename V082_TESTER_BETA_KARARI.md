# Tester Beta kararı

**Yerel Windows teknik deneme paketi hazır. Genel Tester Beta onayı bekliyor.** PyInstaller paketi yerel sistemde görünür olarak açıldı. Python PATH dışında çalıştırılan paket kontrolü veri yükledi, bir hafta oynattı, kaydı yazdı ve yeniden okudu. Bağımsız temiz Windows makinesi veya insan tester oturumu kullanılmadı.

Ali'nin v0.8.1 dosyaları kullanılmadı. v0.8.2 altında ayrı Windows paketi ve BENI_OKU.txt var. Dış testte dosyaların birlikte taşınması, temiz kullanıcı profili altında yazılabilir kayıt, 960×600 ve TR/EN iş akışı önceliklidir. Piyasa kalibrasyonunda özellikle bedelsiz oyuncuların payı ve büyüyen nominal nakit izlenmelidir.
